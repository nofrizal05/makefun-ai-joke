A one-line joke about working beside AI coding agents, written for make.fun's
"The joke the reviewer laughs at" bounty ($35 in USDC).

Bounty page: https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329

## The joke

> My coding agent's PR said 'minor cleanup' — 47 files changed, and the only line it left alone was the bug.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default) and verifies the
written file is identical to the joke.
